# JavaScript Quiz App

A simple interactive Quiz Application built using **HTML, CSS, and JavaScript**.

This project focuses on practicing JavaScript logic, DOM manipulation, event handling, and managing application state.

## Features

- Display multiple quiz questions
- Show multiple-choice options
- Select answers dynamically
- Track correct and wrong answers
- Calculate total score
- Display current question number
- Move between questions using Next button
- Real-time statistics update

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Concepts Practiced

- DOM Manipulation
- Event Listeners
- Arrays and Objects
- Loops
- Conditional Logic
- Dynamic HTML Creation
- State Management
